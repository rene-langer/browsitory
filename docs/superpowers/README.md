# Specs and plans

Design specs (`specs/`) and implementation plans (`plans/`) written with the `superpowers`
plugin, one pair per piece of larger work, named `YYYY-MM-DD-<slug>[-design].md`.

They are a dated record of what was decided and why, not documentation of the current code.
Many describe files, functions or behaviour that later changed. When a spec or plan disagrees
with the code, `AGENTS.md` or `docs/ARCHITECTURE.md`, the latter are right.

When searching the repository for how something works today, prefer the code and
`docs/ARCHITECTURE.md`; come here for the reasoning behind a past change.
