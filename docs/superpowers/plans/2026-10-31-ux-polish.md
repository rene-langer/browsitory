# UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close seven UX follow-ups:

- **#106:** a remote branch's "…" button is named `Actions for <remote>/<branch>`.
- **#141:** the co-author popover flips and shifts at the viewport edges.
- **#146:** a regression test, and focus that never detours, for the palette's commit menu.
- **#154:** clear discard and stash errors when a file stands where a folder was.
- **#157:** staging and unstaging inside a folder that was replaced by a link.
- **#177:** errors survive refreshes and clear on dismiss or when a mutation starts.
- **#178:** a clean merge's `post-merge` shows as a running hook with Cancel.

**Architecture:**

- In `git-core`:
  - `stage.rs`: `stage_file`, `unstage_file`, `discard_file`, `discard_all_unstaged`, and a new
    `StageError::FolderIsNowAFile`;
  - `stash.rs`: a new `StashError::FolderIsNowAFile` pre-check;
  - `worktree_guard.rs`: `file_in_place_of_folder`.
- In `repo-service`: `worker/status.rs` `commit` and `worker/hooks.rs` `run_post_hook_reported`.
- In the frontend:
  - `BranchTree` (label);
  - a new `lib/anchoredPosition.ts` and `CoAuthorPicker`;
  - `CommitGraph` (`returnFocusTo`);
  - `useMutationRunner`, `useAppState.refresh`, `useReflogActions`, `useForgeActions`.
- One VSCode E2E assertion.

**Tech Stack:**

- Rust (`git2` 0.21 / libgit2 1.9);
- React 19 + Vitest + Testing Library (jsdom);
- `@vscode/test-electron` + CDP.

**Spec:** `docs/superpowers/specs/2026-10-31-ux-polish-design.md`. This plan implements the
**provisional** choice of each decision D1–D10. "Decision hooks" at the end lists what changes
for the other options.
