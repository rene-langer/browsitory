# Browsitory documentation

## For users

- **[User guide](guide/README.md)**: how to install and use Browsitory, one page per topic.
  Also published at <https://rene-langer.github.io/browsitory/>.
- [CHANGELOG.md](../CHANGELOG.md): what changed in each version. The app shows the same notes
  under **Release notes**.

## For contributors

- [CONTRIBUTING.md](../CONTRIBUTING.md): build and run Browsitory from source.
- [ARCHITECTURE.md](ARCHITECTURE.md): how the backend, the frontend and the two hosts fit
  together, the IPC contract and the testing strategy.
- [CONTENT_GUIDELINES.md](CONTENT_GUIDELINES.md): how to write labels, messages and errors in
  the UI.
- [LICENSE_COMPLIANCE.md](LICENSE_COMPLIANCE.md): the licence of every dependency and the
  owner's exceptions.
- [RELEASING.md](RELEASING.md): versioning, publishing and the release checklist (maintainers).
- [../AGENTS.md](../AGENTS.md): commands and project rules, written for coding agents.
- [../e2e/screenshots/README.md](../e2e/screenshots/README.md): how the user guide's screenshots
  are made.

## Internal records

Kept for history. They record past decisions and may not match the current code; where they
disagree, the documents above win.

- [superpowers/](superpowers/README.md): design specs and implementation plans, one pair per
  piece of work.
- [tasks/](tasks/): task files from the early phases (retired format, see
  [TASK_TEMPLATE.md](TASK_TEMPLATE.md)).
- [audits/](audits/): code and UX audits and how their findings were resolved.
- [USER_GUIDE.md](USER_GUIDE.md): the old single-page user guide, now a pointer to
  [guide/](guide/README.md).
