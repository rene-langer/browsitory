# Pull requests

For GitHub and Bitbucket remotes, open **Pull requests** in the sidebar. There you can save a
personal access token, list the pull requests, and create a new one from a source branch
into a target branch. Click a pull request's link to open it in your browser.

The section lists nothing until the repository has a GitHub or Bitbucket remote. Add one with
**Add remote…** in the **+** menu of the Branches section.
